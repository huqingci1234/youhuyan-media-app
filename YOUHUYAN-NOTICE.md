Youhuyan Media Android build
=============================

Based on WebHTV, an open-source Android project derived from FongMi/TV
and the CatVod ecosystem:
https://github.com/webhtv/webhtv
https://github.com/FongMi/TV

License: GNU General Public License v3.0 (GPL-3.0). Original license,
copyright notices, and third-party notices are retained.

Branding changes:
- Android application ID: com.youhuyan.media
- Display name: 尤湖沿影视

No third-party video sources, live-TV lists, or JSON configuration
endpoints are bundled. Users must import configurations they are
authorized to use.

## 实现内容

- 仅允许显式调用 HTTPS GET；拒绝 HTTP 地址和带用户名/密码的 URL。
- 保留 API URL 既有 query 参数，并允许调用方追加 ac、pg、wd、分类 ID 等站点参数。
- 关闭 HTTP 客户端自动重定向；手动处理 301/302/303/307/308，最多 3 次，每次重新校验 HTTPS，拒绝降级。
- 整个请求及响应读取共用 20 秒总超时。
- 只接受 HTTP 200；响应流严格限制在 2 MiB；UTF-8 解码失败拒绝。
- 返回文本仅交给既有 JSON 列表/详情解析器；不执行 spider、脚本、JAR，不请求或打开播放源 URL。
- 该网络客户端目前是独立服务层，尚未接入资源目录界面，也没有自动遍历或批量调用用户配置中的 API。

# 开发记录 · 2026-11-23

## 本次里程碑

完成 JSON 站点/直播资源目录模型、离线解析和本地搜索第一版，并接入独立 Flutter 首页导航的「资源」页。

## 变更文件

- lib/models/tvbox_catalog.dart：新增站点、直播分组、内嵌频道及搜索结果模型。
- lib/services/tvbox_catalog_service.dart：从已验证的离线 JSON 缓存映射 sites/lives；只读取元数据，不调用 api、不下载外部播放列表、不执行脚本。
- lib/screens/catalog_screen.dart：新增默认接口资源目录页面，提供站点/直播切换、名称/标识/频道关键字搜索、刷新读取默认缓存。
- lib/screens/home_screen.dart：将原来静态占位的「分类」导航入口替换为「资源」页，保留首页、收藏和个人中心入口。
- test/services/tvbox_catalog_service_test.dart：覆盖常见站点字段、直播分组/频道映射、中文和大小写不敏感搜索、坏结构处理。
- README.md：更新已完成和未完成范围。

## 数据与安全边界

- 只读取 SQLite 中已成功导入/验证的默认 JSON 缓存；不改变配置内容、不重新写入缓存。
- 切换默认接口后，资源页重新读取对应缓存；刷新按钮仅重新读取本地缓存，不触发网络请求。
- 网站 API、spider、JAR、脚本和外部直播清单地址只保留为元数据；本里程碑不发起媒体/API 请求。
- 直播频道只展示 JSON 内嵌的 channels/items 项；若配置仅提供外部 URL，则提示当前未读取外部 live.txt/M3U 播放列表。
- 收藏、观看历史表以及其他接口缓存完全不在本次修改范围内。

## 验证

- 本地自动化执行环境没有可直接使用的 Flutter SDK/Android 模拟器，故未声称本地 `flutter analyze`、`flutter test` 或真机验证通过。

## 安全与数据保护

- 远程 URL 只接受 HTTPS；每次重定向都重新校验，最多 3 次，拒绝 HTTPS 降级到 HTTP。
- DNS/连接与响应体读取共用 20 秒截止时间；响应声明大小和实际流大小分别校验，最大 2 MiB。
- 新数据完整读取并通过 UTF-8/JSON/资源数组验证后才交给 repository。
- 刷新网络失败只记录失败状态和错误，不替换缓存；成功数据由 repository 在 SQLite 事务中替换。
- 本地文件采用流式读取；本地 JSON 同样不能为空或超过 2 MiB。
- 不执行 spider、脚本、JAR、live.txt 里的命令或未知插件。

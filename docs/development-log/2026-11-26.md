## 安全边界

- 播放源和集数 URL 只拆分并保存为字符串，不请求、不跳转、不传给播放器。
- 本次没有加入 spider/JAR/脚本执行能力，也没有抓取或分发任何影视内容。
- 解析器只处理 API 返回的 JSON 数据；真正的网络请求层仍需单独实现 HTTPS、超时、重定向、大小和结构校验。

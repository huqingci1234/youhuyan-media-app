# 开发记录 · 2026-11-25

## 本次里程碑

收藏与观看历史界面 V1 已接入首页导航和 SQLite Repository。此前已完成的数据层现在有实际可访问的界面：用户可以查看收藏、取消收藏、查看本地保存的播放位置/时长/进度、删除单条观看记录或清空观看历史。

## 变更文件

- `lib/screens/media_library_screen.dart`：新增收藏/观看历史列表；支持刷新、取消收藏、删除单条历史、清空历史、空状态及本地读取错误提示。
- `lib/screens/home_screen.dart`：导航新增“历史”；“收藏”不再是占位页；首页“继续观看”入口跳转至历史页。
- `test/screens/media_library_screen_test.dart`：覆盖收藏展示与移除、进度展示、清空历史不影响收藏。
- `README.md`：更新当前已接入功能及尚未完成事项。

## 数据安全

- 界面只读写本地 favorites / watch_history 表，不修改 config_sources。
- 清空历史操作明确只删除观看记录，不清除收藏及任何接口 JSON 缓存。
- 观看记录只展示已保存的毫秒进度；播放器未接入前不会虚构续播能力。
- 用户导入的配置仍只作为受校验的 JSON 数据处理；不执行 spider、JAR、脚本或外部播放列表。

# 开发记录 · 2026-11-21

## 本次里程碑

建立独立 Flutter 分支的 SQLite 多接口数据层第一版。

## 变更文件

- pubspec.yaml：升级最低 Dart SDK 约束到 3.10；加入 sqflite、sqflite_common、sqflite_common_ffi、path 和 path_provider。
- lib/models/tvbox_config_entry.dart：配置记录模型，包含默认状态、来源类型、最近成功/失败状态和缓存 JSON。
- lib/services/tvbox_config_validator.dart：2 MiB 限制、JSON 顶层及 sites/lives/parses 数组校验、HTTPS URL 规范化。
- lib/repositories/tvbox_config_repository.dart：SQLite 多配置 CRUD、重复 URL 检查、唯一默认接口、改 URL 时强制随附新校验 JSON、成功刷新事务替换、失败保留旧缓存。
- test/repositories/tvbox_config_repository_test.dart：多配置、唯一默认、重复 URL、刷新失败保留缓存、改 URL 校验和删除默认接口的单元测试。
- .github/workflows/flutter-independent-ci.yml：Flutter 3.50.0 SDK 检查、依赖解析、analyze、test 和 Android Debug APK 构建。
- README.md：记录独立分支边界、数据库平台策略和当前未完成项。
